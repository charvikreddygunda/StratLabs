# StrategyLab

## Project Goal

StrategyLab is a Python-based application that tests trading strategies using historical stock market data. It allows users to compare trading strategies against a buy-and-hold approach and understand their performance through visualizations and simple explanations.

## Minimum Viable Product (MVP)

The initial version of StrategyLab will include:

- Historical stock price data retrieval using yfinance.
- A moving-average crossover trading strategy.
- Buy and sell signals based on moving averages.
- A backtesting system to simulate trades.
- A buy-and-hold comparison.
- Performance metrics including total return, volatility, and maximum drawdown.
- Interactive performance charts using Plotly.
- A Streamlit dashboard with educational explanations.

## Future Plans

If time allows, I plan to add:

- Support for multiple trading strategies.
- The ability to test multiple stocks.
- Adjustable trading parameters.
- Additional performance metrics.
- More detailed explanations of quantitative finance concepts.

## Tech Stack

- **Python:** Main programming language.
- **pandas:** Organizing and analyzing historical stock data.
- **NumPy:** Numerical calculations.
- **yfinance:** Retrieving historical stock prices.
- **Plotly:** Creating interactive charts.
- **Streamlit:** Building the user interface.
- **unittest:** Testing calculations and application functionality.
- **Git and GitHub:** Version control and project collaboration.
